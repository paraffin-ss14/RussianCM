ScanForFetchItems(EntityUid)

Scans a 5-tile radius around the analyzer for entities matching any active non-marker fetch objective that belongs to the analyzer's faction. For every match found it directly credits that faction (incrementing AmountFetchedPerFaction and marking the item Fetched) and completes the objective when the threshold is reached — exactly as TryHandleFetchItemDropOrUndrag does for the legacy return-point flow. The analyzer machine is the return point. Returns the number of items newly fetched this scan.
